==================================================
Pelvic Range of Motion (ROM) Clinical System UI
==================================================

Overview:
A dashboard UI for tracking and assessing pelvic mobility across the three primary anatomic planes:
1. Sagittal Plane (Anterior / Posterior Tilt)
2. Frontal Plane (Lateral Pelvic Tilt / Obliquity)
3. Transverse Plane (Axial Pelvic Rotation)

Files Included:
- index.html   : Main application interface
- style.css    : Responsive dark-mode styling with clinical layout
- script.js    : Angle calculations, 3D avatar orientation, and CSV logger
- README.txt   : Project setup instructions

How to run:
1. Unzip the archive (if packed) into a single folder.
2. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
